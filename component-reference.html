Component Reference

Two families: Card is bordered independent units, gapped apart. Table / Key-Value / Process / Metric / Chart share one bordered strip with internal hairline dividers — a single structured record. Real content pulled from T-01, C-01, and F-02.

01

Callout

Four variants: question (accent bar), note (tinted fill), quote (outline), caution (top rule, no fill). Takeaway is our own dark addition for closing statements.

Research question

How can synthetic users and AI auditors be calibrated against human participants before we rely on them for pre-deployment evaluation?

Synthetic response = Person × Context × Measurement × Model

"An AI auditor is not a neutral ruler."

Small evaluation set — calibration gaps should be interpreted cautiously, not as fixed error rates.
Design takeaway

Synthetic evaluation should not be trusted because it looks human-like. It should be trusted only to the extent that it has been calibrated against humans.
